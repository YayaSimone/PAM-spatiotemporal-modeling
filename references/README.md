# Scientific References

## Purpose

This bibliography documents the scientific and
computational literature informing the theoretical
research framework.

Published evidence is distinguished from original
modeling assumptions and computational observations.

- Model parameters remain hypothetical.
- Computational observations are not experimental findings.
- Additional literature review and biological validation
  remain outstanding.
